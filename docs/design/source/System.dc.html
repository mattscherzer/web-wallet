FAB menu, toolbars, app bars

Money inMoney out

Medium FAB (80, corner 20, accessible name “Record”) opens a FAB menu: Money in, Money out, Transfer, each icon + word, 56dp items, 16dp margins. Choosing one opens Unlock if locked, then the form with the type preset. Docked toolbar on Count cash, floating toolbar for Edit and Remove on an entry; neither ever shown with the nav bar. Overview uses a flexible app bar with subtitle; History a search app bar.
